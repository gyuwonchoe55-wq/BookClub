# 2. 기능 상세

## F01. 독서모임 생성

### 목적

새로운 독서모임을 만들고 첫 번째 회차까지 한 번에 생성한다.

### 사용자

모임장

### 입력

- 모임명
- 내 별명
- 첫 번째 책 제목
- 모임 날짜(선택)

### 동작

1. 사용자가 독서모임 생성 정보를 입력한다.
2. [독서모임 만들기] 버튼을 누른다.
3. 독서모임을 생성한다.
4. 입력한 별명으로 첫 번째 참여자를 생성하고 모임장으로 지정한다.
5. 첫 번째 회차를 생성한다.
6. 독서모임의 참여 링크를 생성한다.
7. 생성이 완료되면 해당 독서모임방으로 이동한다.

### 예외

- 모임명 미입력 → 생성 불가
- 별명 미입력 → 생성 불가
- 책 제목 미입력 → 생성 불가
- 생성 실패 → 오류 안내 후 입력 내용을 유지한다.

### 완료 조건

- 독서모임이 생성된다.
- 모임장이 생성된다.
- 첫 번째 회차가 생성된다.
- 독서모임방으로 이동한다.

---

## F02. 독서모임방 조회

### 목적

독서모임의 현재 상태를 확인하고 주요 기능을 시작한다.

독서모임방은 서비스의 중심 허브 화면이다.

### 사용자

모임장 / 참여자

### 표시 정보

#### 독서모임

- 모임명

#### 현재 회차

- 책 제목
- 모임 날짜
- 진행 상태

#### 참여자

- 참여자 목록
- 모임장 여부
- 독서 기록 작성 여부

### 주요 행동

모임장은 다음 기능을 사용할 수 있다.

- 참여 링크 공유
- 독서 기록 작성/수정
- 모임 시작
- 새 회차 생성
- 지난 회차 확인

참여자는 다음 기능을 사용할 수 있다.

- 독서 기록 작성/수정
- 현재 회차 확인
- 참여자 현황 확인
- 지난 회차 확인

### 완료 조건

사용자가 독서모임의 현재 상태와 자신이 해야 할 다음 행동을 확인할 수 있다.

---

## F03. 참여 링크 공유

### 목적

모임장이 다른 참여자를 독서모임에 초대한다.

### 사용자

모임장

### 동작

1. 모임장이 독서모임방에서 [참여 링크 복사]를 누른다.
2. 해당 독서모임의 참여 링크를 클립보드에 복사한다.
3. 복사 완료 상태를 사용자에게 안내한다.

### 정책

- 참여 링크는 회차가 아닌 독서모임 단위로 생성한다.
- 같은 링크를 이후 회차에서도 사용할 수 있다.

### 완료 조건

참여 링크가 정상적으로 복사된다.

---

## F04. 독서모임 참여

### 목적

초대받은 사용자가 회원가입 없이 독서모임에 참여한다.

### 사용자

참여자

### 입력

- 별명

### 동작

1. 사용자가 공유받은 참여 링크에 접속한다.
2. 참여할 독서모임 정보를 확인한다.
3. 별명을 입력한다.
4. [참여하기] 버튼을 누른다.
5. 해당 독서모임의 참여자로 등록한다.
6. 독서모임방으로 이동한다.

### 예외

- 별명 미입력 → 참여 불가
- 유효하지 않은 참여 링크 → 참여 불가 및 안내 표시
- 참여 처리 실패 → 오류 안내

### 완료 조건

- 사용자가 독서모임의 참여자로 등록된다.
- 독서모임방으로 이동한다.

---

## F05. 독서 기록 작성/수정

### 목적

현재 회차에서 사용할 독서 기록을 작성한다.

작성된 기록은 실제 모임 진행 콘텐츠로 사용된다.

### 사용자

모임장 / 참여자

### 입력

- 인상 깊은 문장
- 이야기하고 싶은 질문
- 적용점 또는 기억하고 싶은 한 가지

### 동작

1. 독서모임방에서 [독서 기록 작성]을 선택한다.
2. 세 가지 기록을 입력한다.
3. [저장] 버튼을 누른다.
4. 현재 회차의 독서 기록으로 저장한다.
5. 저장 완료 후 독서모임방으로 이동한다.
6. 독서모임방에서 해당 참여자의 기록 상태를 작성 완료로 표시한다.

### 수정

모임 시작 전에는 기존 기록을 다시 열어 수정할 수 있다.

### 정책

- 참여자 한 명은 하나의 회차에 하나의 독서 기록만 작성할 수 있다.
- 기록은 해당 회차에 귀속된다.
- 모임 시작 전까지만 수정할 수 있다.

### 완료 조건

- 독서 기록이 현재 회차에 저장된다.
- 독서모임방에서 작성 완료 여부를 확인할 수 있다.

---

## F06. 모임 시작

### 목적

현재 회차의 독서모임 진행을 시작한다.

### 사용자

모임장

### 동작

1. 모임장이 독서모임방에서 [모임 시작]을 누른다.
2. 현재 회차의 진행 세션을 시작한다.
3. 회차의 진행 상태를 진행 중으로 변경한다.
4. STEP 1 아이스브레이킹 화면으로 이동한다.

### 정책

- 모임장만 모임을 시작할 수 있다.
- 모임이 시작되면 독서 기록을 수정할 수 없다.
- 진행은 STEP 1부터 시작한다.

### 완료 조건

- 진행 세션이 시작된다.
- STEP 1 화면으로 이동한다.

---

# 3. 모임 진행

## F07. STEP 1 — 아이스브레이킹

### 목적

참여자들이 작성한 문장을 활용하여 자연스럽게 대화를 시작한다.

### 사용자

모든 참여자

### 진행 방식

1. 참여자의 '인상 깊은 문장' 중 하나를 공개한다.
2. 작성자 정보는 처음에는 공개하지 않는다.
3. 참여자들이 작성자를 맞힌다.
4. 정답을 공개한다.
5. 작성자가 해당 문장을 선택한 이유를 이야기한다.
6. 다음 문장으로 이동한다.
7. 모든 문장을 진행하면 STEP 2로 이동한다.

### 표시 정보

- 현재 문장
- 현재 진행 순서
- 전체 문장 수
- 작성자 공개 상태
- 진행률

### 완료 조건

모든 참여자의 문장을 진행하면 STEP 1이 완료된다.

---

## F08. STEP 2 — 발제문 토론

### 목적

참여자들이 작성한 질문을 중심으로 토론을 진행한다.

### 사용자

모든 참여자

### 진행 방식

1. 참여자가 작성한 질문을 하나씩 공개한다.
2. 질문 작성자를 표시한다.
3. 해당 질문을 중심으로 대화한다.
4. 질문별 타이머를 제공한다.
5. [다음 질문]을 눌러 다음 질문으로 이동한다.
6. 모든 질문이 끝나면 STEP 3으로 이동한다.

### 표시 정보

- 현재 질문
- 질문 작성자
- 현재 질문 번호
- 전체 질문 수
- 남은 시간
- 진행률

### 완료 조건

모든 질문을 진행하면 STEP 2가 완료된다.

---

## F09. STEP 3 — 마무리

### 목적

각 참여자가 이번 독서를 통해 얻은 적용점 또는 기억하고 싶은 내용을 공유한다.

### 사용자

모든 참여자

### 진행 방식

1. 참여자의 '적용점 또는 기억하고 싶은 한 가지'를 순차적으로 공개한다.
2. 해당 참여자가 자신의 내용을 공유한다.
3. 다음 참여자의 내용으로 이동한다.
4. 모든 참여자의 공유가 끝나면 모임을 종료할 수 있다.

### 표시 정보

- 현재 공유 내용
- 작성자
- 현재 순서
- 전체 참여자 수
- 진행률

### 완료 조건

모든 참여자의 내용을 확인하면 STEP 3이 완료된다.

---

## F10. 모임 종료

### 목적

현재 회차의 진행을 완료한다.

### 사용자

모임장 / 참여자

### 동작

1. STEP 3 완료 후 모임 종료 화면을 표시한다.
2. 현재 회차의 진행 상태를 완료로 변경한다.
3. [독서모임방으로 돌아가기]를 제공한다.
4. 독서모임방으로 이동한다.

### 완료 조건

- 현재 회차가 완료 상태가 된다.
- 사용자가 독서모임방으로 돌아갈 수 있다.

---

# 4. 회차 관리

## F11. 새 회차 생성

### 목적

기존 독서모임에서 다음 독서모임 회차를 이어간다.

### 사용자

모임장

### 입력

- 책 제목
- 모임 날짜(선택)

### 동작

1. 모임장이 독서모임방에서 [새 회차 만들기]를 선택한다.
2. 책 제목과 모임 날짜를 입력한다.
3. 새로운 회차를 생성한다.
4. 생성된 회차를 현재 회차로 표시한다.
5. 독서모임방으로 돌아간다.
6. 참여자들은 새 회차에 대해 새로운 독서 기록을 작성할 수 있다.

### 정책

- 새 회차는 기존 독서모임에 속한다.
- 기존 참여자는 그대로 유지한다.
- 이전 회차의 독서 기록은 새 회차로 복사하지 않는다.

### 완료 조건

- 새로운 회차가 생성된다.
- 새 회차가 독서모임방에 표시된다.

---

## F12. 지난 회차 확인

### 목적

같은 독서모임에서 이전에 진행한 회차를 확인한다.

### 사용자

모임장 / 참여자

### 표시 정보

- 책 제목
- 모임 날짜
- 진행 상태

### 동작

1. 독서모임방에서 지난 회차를 확인한다.
2. 회차 목록에서 이전 회차 정보를 확인한다.

### MVP 범위

지난 회차의 상세 기록 조회 기능은 MVP에서 필수로 구현하지 않는다.

회차가 존재했다는 사실과 기본 정보 확인을 우선 제공한다.

---

# 5. 공통 기능 규칙

## 사용자 식별

MVP에서는 회원가입과 로그인을 사용하지 않는다.

사용자는 독서모임 참여 시 입력한 별명을 기준으로 참여한다.

사용자 식별을 실제 브라우저에서 어떻게 유지할지는 개발 설계 단계에서 결정한다.

---

## 권한

### 모임장

- 참여 링크 공유
- 독서 기록 작성/수정
- 모임 시작
- 새 회차 생성

### 참여자

- 독서 기록 작성/수정
- 독서모임 정보 확인
- 모임 진행 참여

---

## 회차 상태

회차는 최소 다음 상태를 가진다.

```text
진행 전
  ↓
진행 중
  ↓
완료
```

---

## 독서 기록 상태

```text
미작성
  ↓
작성 완료
```

모임 시작 전에는 작성 완료 상태의 기록을 수정할 수 있다.

---

## 진행 순서

모임 진행 단계는 다음 순서를 따른다.

```text
STEP 1
아이스브레이킹

↓

STEP 2
발제문 토론

↓

STEP 3
마무리

↓

모임 종료
```

MVP에서는 진행 순서를 임의로 변경하지 않는다.

---

# 6. MVP 구현 원칙

- 독서모임방을 주요 기능의 시작점으로 사용한다.
- 새로운 화면을 불필요하게 추가하지 않는다.
- 모임 진행에 필요한 기능을 우선 구현한다.
- 회원가입, 로그인 등 MVP 검증에 필수적이지 않은 기능은 추가하지 않는다.
- 모바일과 PC 모두 사용할 수 있는 반응형 웹을 기준으로 한다.
- 실제 독서모임에서 빠르게 사용해볼 수 있는 수준의 구현을 우선한다.
