# 도메인 정의서

## 문서 목적

이 문서는 독서모임 진행 서비스의 핵심 도메인과 각 도메인의 역할, 관계를 정의한다.

도메인을 명확히 정의하여 기획, 설계, 개발 과정에서 동일한 용어와 개념을 사용하도록 한다.

---

# 1. 독서모임 (Book Club)

## 설명

사용자들이 지속적으로 함께 활동하는 독서모임이다.

독서모임은 여러 번의 모임(회차)을 가지며, 참여자와 모임 정보를 관리하는 최상위 단위이다.

## 주요 역할

- 독서모임 생성
- 참여자 관리
- 참여 링크 관리
- 모임(회차) 관리

## 포함 정보

- 모임명
- 생성일
- 생성자
- 참여 링크
- 참여자 목록
- 모임(회차) 목록

---

# 2. 모임 (Meeting)

## 설명

독서모임 안에서 특정 날짜에 진행되는 하나의 회차이다.

하나의 모임은 일반적으로 하나의 책을 중심으로 진행되지만,
회차의 기준은 '책'이 아니라 '모임'이다.

모든 독서 기록과 진행 상태는 모임(회차)을 기준으로 관리한다.

## 주요 역할

- 회차 생성
- 책 정보 관리
- 진행 상태 관리
- 독서 기록 관리

## 포함 정보

- 책 제목
- 모임 날짜
- 진행 상태
- 생성일

---

# 3. 참여자 (Member)

## 설명

독서모임에 참여하는 사용자이다.

회원가입 없이 별명만 입력하여 참여한다.

참여자는 독서모임에 소속되며,
각 모임(회차)에 참여하여 독서 기록을 작성하고 토론에 참여한다.

## 주요 역할

- 독서모임 참여
- 독서 기록 작성
- 토론 참여

## 포함 정보

- 별명
- 모임장 여부
- 참여일

---

# 4. 독서 기록 (Reading Record)

## 설명

참여자가 특정 모임(회차)에 대해 작성하는 기록이다.

모든 진행 콘텐츠는 독서 기록을 기반으로 생성된다.

## 주요 역할

- 아이스브레이킹 자료 제공
- 토론 질문 제공
- 적용점 공유

## 포함 정보

- 인상 깊은 문장
- 이야기하고 싶은 질문
- 적용점 또는 기억하고 싶은 한 가지
- 작성자
- 작성일

---

# 5. 진행 세션 (Session)

## 설명

모임이 시작된 이후 진행되는 실시간 진행 상태이다.

진행 세션은 현재 어느 단계까지 진행되었는지 관리한다.

## 주요 역할

- 현재 STEP 관리
- 현재 질문 관리
- 진행률 관리
- 타이머 관리

## 진행 단계

STEP 1. 아이스브레이킹

↓

STEP 2. 발제문 토론

↓

STEP 3. 적용점 또는 기억하고 싶은 한 가지 공유

↓

모임 종료

---

# 도메인 관계

Book Club

├── 1 : N → Meeting

├── 1 : N → Member

↓

Meeting

├── 1 : N → Reading Record

└── 1 : 1 → Session

Member

└── 1 : N → Reading Record

---

# 용어 정의

| 용어 | 정의 |
|------|------|
| 독서모임 (Book Club) | 지속적으로 운영되는 하나의 독서모임 |
| 모임 (Meeting) | 독서모임 안에서 진행되는 하나의 회차 |
| 참여자 (Member) | 독서모임에 참여하는 사용자 |
| 독서 기록 (Reading Record) | 참여자가 특정 모임(회차)에 대해 작성하는 기록 |
| 진행 세션 (Session) | 실제 모임 진행 상태를 관리하는 객체 |

---

# 도메인 규칙

## 독서모임

- 하나 이상의 모임(회차)을 가진다.
- 참여 링크는 독서모임 단위로 관리한다.
- 참여자는 독서모임 단위로 소속된다.

## 모임

- 반드시 하나의 독서모임에 속한다.
- 하나의 회차는 하나의 진행 세션을 가진다.
- 하나의 회차는 여러 개의 독서 기록을 가진다.

## 참여자

- 반드시 하나의 독서모임에 속한다.
- 여러 회차에 참여할 수 있다.
- 각 회차마다 하나의 독서 기록만 작성할 수 있다.

## 독서 기록

- 참여자는 동일한 회차에 하나의 독서 기록만 작성할 수 있다.
- 모임 시작 전까지 수정할 수 있다.

## 진행 세션

- 하나의 회차에는 하나의 진행 세션만 존재한다.
- 진행은 STEP 순서대로만 진행된다.
