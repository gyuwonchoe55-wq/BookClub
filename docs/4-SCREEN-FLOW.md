# 화면 목록 및 사용자 플로우 (Screen Flow)

## 문서 목적

이 문서는 독서모임 진행 서비스의 화면 목록과 사용자 이동 흐름을 정의한다.

화면 간 이동 관계를 명확히 하여 UI 설계와 개발의 기준으로 활용한다.

**독서모임방(Book Club Room)을 서비스의 중심 화면으로 하며,**
참여자 관리, 회차 확인, 독서 기록 작성, 모임 시작, 새 회차 생성 등의 주요 행동은 독서모임방에서 시작한다.

---

# 1. 화면 목록

| 화면 ID | 화면명         | 주요 목적                                                 |
| ------- | -------------- | --------------------------------------------------------- |
| S01     | 랜딩           | 서비스 진입 및 독서모임 생성 시작                         |
| S02     | 독서모임 생성  | 독서모임과 첫 번째 회차 생성                              |
| S03     | 독서모임방     | 독서모임의 중심 화면. 참여자·회차·독서기록·모임 진행 관리 |
| S04     | 참여하기       | 참여 링크를 통한 독서모임 참여                            |
| S05     | 독서 기록 작성 | 현재 회차의 독서 기록 작성 및 수정                        |
| S06     | 모임 진행      | STEP 1~3에 따라 독서모임 진행                             |
| S07     | 모임 종료      | 현재 회차 종료 및 독서모임방 복귀                         |
| S08     | 새 회차 생성   | 같은 독서모임에서 다음 회차 생성                          |

# 3. 화면 상세

## S01. 랜딩

### 목적

서비스를 소개하고 새로운 독서모임 생성을 시작한다.

### 주요 기능

- 서비스 핵심 가치 안내
- 독서모임 만들기

### 이동

- 독서모임 만들기 → S02 독서모임 생성

---

## S02. 독서모임 생성

### 목적

새로운 독서모임을 만들면서 모임장의 정보와 첫 번째 회차를 함께 생성한다.

### 입력 정보

**독서모임**

- 모임명

**모임장**

- 내 별명

**첫 번째 회차**

- 책 제목
- 모임 날짜(선택)

### 주요 기능

- 독서모임 생성
- 모임장 생성
- 첫 번째 회차 생성

### 이동

생성 성공 → S03 독서모임방

---

# S03. 독서모임방

## 목적

독서모임의 **중심 허브 화면**이다.

사용자는 독서모임방에서 현재 모임의 상태를 파악하고, 독서 기록 작성부터 실제 모임 시작까지 필요한 주요 행동을 수행한다.

모임이 종료된 이후에도 다시 독서모임방으로 돌아오며, 이후 새로운 회차를 생성하여 같은 독서모임을 계속 운영한다.

## 표시 정보

### 독서모임 정보

- 모임명

### 현재 회차

- 책 제목
- 모임 날짜
- 진행 상태

### 참여자

- 참여자 목록
- 참여자별 독서 기록 작성 여부
- 모임장 표시

## 주요 기능

### 참여자 초대

- 참여 링크 복사

### 독서 기록

- 내 독서 기록 작성
- 작성한 독서 기록 수정
- 참여자별 작성 여부 확인

### 모임 진행

- 모임 시작

### 회차 관리

- 현재 회차 확인
- 지난 회차 확인
- 새 회차 생성

## 주요 이동

```text
독서모임방
│
├─ 독서 기록 작성 → S05
│
├─ 모임 시작 → S06
│
└─ 새 회차 생성 → S08
```

---

## S04. 참여하기

### 목적

공유받은 참여 링크를 통해 기존 독서모임에 참여한다.

회원가입이나 로그인 없이 별명만 입력한다.

### 입력 정보

- 별명

### 주요 기능

- 독서모임 참여

### 이동

참여 완료 → S03 독서모임방

---

## S05. 독서 기록 작성

### 목적

현재 회차에서 사용할 독서 기록을 작성한다.

작성된 내용은 실제 모임 진행 콘텐츠로 사용된다.

### 입력 정보

- 01 인상 깊은 부분 (필수) / 페이지 (선택)
- 02 발제: 발제 질문 (필수) / 함께 읽을 본문 (선택) / 발제자의 말 (선택)
- 03 한줄평 (필수)

### 주요 기능

- 독서 기록 저장
- 독서 기록 수정

### 정책

- 참여자별 회차당 하나의 독서 기록을 작성한다.
- 모임 시작 전까지 수정할 수 있다.

### 이동

저장 완료 → S03 독서모임방

---

# S06. 모임 진행

## 목적

별도의 진행자가 없어도 서비스의 안내에 따라 독서모임을 진행한다.

모임은 **인트로, 진행 1, 진행 2, 마무리** 4단계로 구성된다.

각 단계에서 현재 단계, 진행률, 남은 시간 등 진행에 필요한 정보를 제공한다.

상단 탭(인트로 / 진행 1 / 진행 2 / 마무리)으로 단계를 자유롭게 이동할 수 있다. 탭 이동 시 세션의 현재 단계(`session.current_step`)도 함께 갱신되므로, 모임을 나갔다가 "모임 이어서 진행하기"를 눌러도 마지막으로 이동한 단계부터 다시 시작한다. "끝내기"는 탭이 아니며 모임 종료 동작을 담당한다.

---

## INTRO. 인트로

### 목적

본격적인 기록 공유와 토론 전에 책에 대한 첫 감상을 자유롭게 나누는 단계.

### 화면 구성

- 책 제목
- "어떻게 읽었나요?"라는 질문
- 다음 단계로 이동하는 버튼

### 주요 기능

- 참여자들이 자유롭게 책 감상을 이야기한다.
- 참여자별 순서를 시스템에서 지정하지 않는다.
- 별도의 사전 기록을 요구하지 않는다.

### 진행 방식

- 사회자(모임장) 진행 및 참여자 발언
- 발언 내용을 별도로 기록하지 않음

인트로 완료 → 다음 단계 이동

↓

진행 1

## 진행 1. 인상 깊은 부분

### 목적

참여자들이 사전에 작성한 인상 깊은 부분을 순차적으로 확인하며 이야기를 나눈다.

### 데이터 기반

reading_record.memorable_quote, reading_record.memorable_quote_page (선택, 비어 있으면 미표시)

### 주요 기능

- 참여자가 작성한 인상 깊은 문장 공개
- 페이지 표시 (값이 있을 때만)
- 작성자 표시
- 현재 항목 번호 표시
- 다음 항목 이동

모든 인상 깊은 부분 진행 완료

↓

진행 2

---

## 진행 2. 발제 토론

### 목적

참여자들이 작성한 발제문을 순차적으로 확인하며 토론한다.

### 데이터 기반

reading_record.discussion_question, reading_record.discussion_passage (선택), reading_record.discussion_note (선택)

### 주요 기능

- 참여자가 작성한 질문 순차 공개
- 함께 읽을 본문 표시 (값이 있을 때만)
- 발제자의 말 표시 (값이 있을 때만)
- 질문 작성자 표시
- 현재 질문 번호 표시
- 질문별 타이머
- 다음 질문 이동

모든 질문 진행 완료

↓

# 4. 화면 설계 원칙

## 독서모임방 중심

사용자가 주요 기능을 찾기 위해 여러 화면을 탐색하지 않도록 한다.

독서모임방에서 다음 행동을 바로 시작할 수 있어야 한다.

- 참여자 초대
- 독서 기록 작성
- 모임 시작
- 새 회차 생성

## 진행 경험 중심

모임 진행 중에는 관리 기능보다 현재 대화에 집중할 수 있도록 한다.

현재 해야 할 행동과 다음 행동을 명확하게 보여준다.

## 모바일 / PC 대응

모든 화면은 모바일과 PC에서 사용할 수 있는 반응형 웹으로 구현한다.

모바일에서도 모임 진행에 필요한 핵심 정보와 주요 버튼을 쉽게 확인하고 조작할 수 있도록 한다.

## MVP 우선

1주 MVP에서는 새로운 화면을 불필요하게 추가하지 않는다.

가능한 기능은 독서모임방과 모임 진행 화면 안에서 해결하고, 실제 사용 검증 이후 필요할 경우 화면을 확장한다.
